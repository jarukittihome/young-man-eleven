# ชตุกรรณีมาณพปุจฉา (Jatukanni Manava Puccha) 🪷

> **ปุจฉาที่ ๑๑ จาก โสฬสปัญหา ปารายนวรรค สุตตนิบาต ขุททกนิกาย พระสุตตันตปิฎก**

โปรเจกต์นี้นำเสนอเนื้อหาและธรรมวิจารณ์ของ **ชตุกรรณีมาณพปุจฉา** หนึ่งใน ๑๖ คำถาม (โสฬสปัญหา) คำถามนี้มุ่งเน้นแสวงหา "สันติธรรม" เพื่อการหลุดพ้นจากวัฏสงสาร การเกิด ความแก่ และความตาย (มัจจุราช)

---

## 📖 แก่นธรรมหลัก (Core Teachings)

ชตุกรรณีมาณพได้กราบทูลถามถึงธรรมอันเป็นเครื่องละความเกิดและความชรา พระผู้มีพระภาคเจ้าได้ทรงแสดงหนทางแห่งความสงบ (สันติธรรม) ไว้ดังนี้:

1. **เห็นความเกษมในเนกขัมมะ:** การละทิ้งความกำหนัดยินดีในกามคุณทั้งปวง และมองเห็นการสละออก (เนกขัมมะ) ว่าเป็นที่พึ่งอันปลอดภัยจากความทุกข์
2. **การไม่ยึดมั่นในกาลทั้ง ๓:** ละความกังวลยึดมั่นในสิ่งอดีต ไม่คาดหวังทะยานอยากในอนาคต และไม่ยึดถือปรุงแต่งในปัจจุบัน
3. **พ้นอำนาจมัจจุราชด้วยการละนามรูป:** เมื่อละความเพลิดเพลินใน "นามรูป" (กายและใจ) ได้เด็ดขาด อาสวะกิเลสย่อมสิ้นไป และมัจจุราชจะไม่สามารถมองเห็นหรือครอบงำผู้นั้นได้อีก

  *ออกแบบ UI/UX โดยคำนึงถึงความงดงามทางศิลปะ เรียบง่าย สงบ และใช้หลัก Typography ที่เอื้อต่อการน้อมจิตพิจารณาธรรม*

## 💻 การใช้งาน (Usage)
